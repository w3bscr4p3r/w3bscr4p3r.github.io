# w3bscr4p3r.github.io

Repositório pessoal de páginas estáticas hospedadas no GitHub Pages, com diversas interfaces web, dashboards, simuladores e clones de produtos digitais desenvolvidos em HTML, CSS e JavaScript.

O objetivo principal do projeto é servir como portfólio técnico e sandbox de front-end, reunindo demonstrações de design, UX, interatividade e prototipagem visual em um único site estático.

## Visão geral

Este repositório reúne vários projetos e páginas independentes, cada um com foco em uma experiência diferente:

- dashboards e painéis de dados
- calculadoras e ferramentas de produtividade
- interfaces de segurança e OSINT
- páginas institucionais / landing pages
- clones de plataformas populares
- blog / relatórios editoriais de tecnologia e cibersegurança

Todos os projetos são estáticos e podem ser abertos diretamente ou publicados via GitHub Pages, sem necessidade de backend.

## Projetos principais

### DashboardOSINT
Painel de monitoramento e busca com visual de cibersegurança e inteligência de código aberto.

### MacroCalculator
Calculadora de macros, IMC e metas de saúde/fitness com layout moderno e interativo.

### NexusDev
Landing page de empresa / agência digital com visual tecnológico e componentes sofisticados.

### SherlockRecon
Página focada em recon / OSINT com estrutura de busca e exploração em contexto de cibersegurança.

### StudyPlan
Dashboard de planejamento e organização de estudos com visão semanal/mensal.

### blog
Relatório e publicação editorial com foco em cibersegurança, tendências, ameaças e incidentes relevantes.

### clone-da-netflix
Interface inspirada no layout do serviço de streaming Netflix.

### clone-do-instagram
Página de apresentação e login inspirada na interface do Instagram.

## Como usar

1. Clone o repositório:

```bash
git clone https://github.com/w3bscr4p3r/w3bscr4p3r.github.io.git
```

2. Entre na pasta desejada e abra o arquivo `index.html` no navegador.

3. Para visualizar como site GitHub Pages, publique o repositório com GitHub Pages habilitado.
